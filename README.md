# cru-latex-templete
เพราะความขี้เกียจมันครอบงำ เราเลยต้องหาทางที่ดีกว่าในการทำวิจัย

## ทำไมถึงมีสิ่งนี้ออกมา
เอาตรงๆ คือ ขี้เกียจเขียนเล่มครับผม ถ้าเรารู้ว่าเราจะทำรายงานที่มันเขียนเยอะมากๆ แล้วปัญหาคือ
*"การจัดหน้า และแบบฟอร์มไม่เหมือนกันสักอันเดียว"* โดยได้ไอเดียนี้มาจากหลายมหาวิทยาลัยดังที่มีการใช้งาน LaTeX
ซึ่งคิดว่ามันน่าจะดีมากๆ เลย ถ้าเราเอามาแทน MS Word ในการเขียนวิจัย และง่ายต่อการที่เราจะเอาไป Integrated กับ
AI Agent ได้ง่ายยิ่งขึ้น

เอาจริงๆ อยากจะทำให้ง่ายยิ่งขึ้น แต่ว่าต้องหาเวลาพัฒนาด้วย ผมเลยคิดว่า *"ถ้าเราทำเหมือนต้นแบบขึ้นมาก่อน แล้วปล่อยให้ได้ลองใช้งาน ผมว่ามันก็ดีไม่น้อยเลยที่จะได้เห็นอะไรหลายอย่างจากผู้ใช้เหมือนกันที่ได้ลองอะไรแบบนี้ด้วย"*

## ความต้องการของซอฟต์แวร์
- Docker
    - ใช้สำหรับ Render เอกสารเป็น PDF โดยไม่ต้องติดตั้ง LaTeX และฟอนต์ลงในเครื่อง

## การ Compile ด้วย Docker

โปรเจกต์ใช้ XeLaTeX เพื่อรองรับ Unicode และภาษาไทย โดยโหลดฟอนต์ TH Sarabun New
จากโฟลเดอร์ `fonts/` โดยตรง

Build image และ Compile `main.tex` ด้วยคำสั่ง:

```bash
docker-compose run --rm latex
```

คำสั่งข้างต้นใช้ Docker Compose แบบ standalone ซึ่งติดตั้งอยู่ในเครื่องนี้
หากเครื่องอื่นติดตั้ง Compose plugin รุ่นใหม่ สามารถเปลี่ยน `docker-compose`
เป็น `docker compose` ได้

เมื่อสำเร็จจะได้ไฟล์ `main.pdf` อยู่ในโฟลเดอร์โปรเจกต์ หากแก้ไขไฟล์แล้วสามารถใช้คำสั่งเดิมซ้ำได้

## โครงสร้างเอกสาร

แก้ข้อมูลชื่อเรื่อง ผู้จัดทำ ชื่อวิชา สาขาวิชา และอาจารย์ที่ปรึกษาที่
`chapters/0_basic-info.tex` จากนั้นเขียนเนื้อหาแยกตามไฟล์ดังนี้

- `chapters/0_*.tex` ส่วนต้น เช่น ปก บทคัดย่อ และกิตติกรรมประกาศ
- `chapters/1_introduction.tex` บทที่ 1 บทนำ
- `chapters/2_literature-review.tex` บทที่ 2 เอกสารและงานวิจัยที่เกี่ยวข้อง
- `chapters/3_methodology.tex` บทที่ 3 วิธีดำเนินการวิจัย
- `chapters/4_results.tex` บทที่ 4 ผลการวิจัย
- `chapters/5_conclusion.tex` บทที่ 5 สรุป อภิปรายผล และข้อเสนอแนะ
- `chapters/references.tex` บรรณานุกรม
- `chapters/appendix-a.tex` ภาคผนวก
- `figures/` รูปภาพ แผนภูมิ และแผนภาพที่ใช้ในเอกสาร
- `logo/cru_logo.png` ตรามหาวิทยาลัยที่แสดงบนหน้าปก

ไฟล์ `main.tex` ทำหน้าที่กำหนดรูปแบบและรวมทุกส่วนเข้าด้วยกัน

เลขหน้าส่วนต้นตั้งแต่บทคัดย่อถึงสารบัญใช้ตัวอักษรไทย `ก ข ค ...`
ส่วนเนื้อหาตั้งแต่บทที่ 1 เป็นต้นไปใช้เลขอารบิก `1 2 3 ...`

## การตั้งค่าระยะขอบและหัวบท

ค่าระยะขอบกระดาษกำหนดใน `main.tex` ดังนี้:

```latex
\geometry{top=3.81cm,bottom=2.54cm,left=3.81cm,right=2.54cm}
```

ระยะห่างบรรทัดตั้งเป็น 1.0 หรือ Single เช่นเดียวกับ Line Spacing ใน Word:

```latex
\singlespacing
```

หากต้องการระยะห่าง 1.5 ให้เปลี่ยนเป็น `\onehalfspacing`

รูปแบบตัวอักษรอ้างอิงจากเล่ม Word เดิม โดยใช้ TH Sarabun New ขนาด 16 pt
สำหรับเนื้อหา หัวบทขนาด 18 pt ตัวหนาและจัดกึ่งกลาง โดยเลขบท เช่น `บทที่ 1`
และชื่อบท เช่น `บทนำ` อยู่คนละบรรทัด ส่วนย่อหน้าบรรทัดแรกประมาณ 0.25 นิ้ว

เมื่อต้องการขึ้นย่อหน้าใหม่ ให้เว้นบรรทัดว่างหนึ่งบรรทัดในไฟล์ `.tex`
ระบบจะย่อหน้าให้อัตโนมัติ ไม่ต้องเติม `\quad`, `\qquad` หรือช่องว่างด้วยตนเอง

รายการ `enumerate` และ `itemize` ถูกตั้งให้ใช้ระยะบรรทัด 1.0 และไม่มีช่องว่าง
เพิ่มเติมระหว่าง `\item` หากต้องการเพิ่มเฉพาะรายการใด ให้กำหนด option เช่น
`\begin{enumerate}[itemsep=6pt]`

ระยะก่อนและหลังหัวบทแยกเป็นค่าตั้งไว้ให้ปรับได้ โดยคำนวณต่อจากพื้นที่ข้อความ
ที่กำหนดด้วย `geometry`:

```latex
\setlength{\chapterBeforeSpace}{0pt} % ระยะเพิ่มจากขอบบนของพื้นที่ข้อความ
\setlength{\chapterAfterSpace}{19.2pt} % เว้นหนึ่งบรรทัดก่อนเริ่มหัวข้อแรก
```

หากต้องการเลื่อนชื่อบทลง ให้เพิ่ม `chapterBeforeSpace` เป็นค่าบวก เช่น `12pt`
โดยไม่ต้องเปลี่ยนระยะขอบกระดาษ

ช่องว่างหลังหัวข้อย่อย เช่น `1.1` และ `1.1.1` ถูกกำหนดเป็น `0pt`
เพื่อให้ย่อหน้าแรกต่อจากหัวข้อด้วยระยะบรรทัดปกติ:

```latex
\titlespacing*{\section}{0pt}{12pt}{0pt}
\titlespacing*{\subsection}{0pt}{6pt}{0pt}
```

รายการในสารบัญใช้ระยะบรรทัดแบบกระชับเฉพาะหน้าสารบัญด้วย
`\setstretch{1.0}` และคงช่องว่างก่อนรายการระดับบทไว้ที่ `1em`
โดยไม่กระทบระยะบรรทัดของเนื้อหา

หากต้องการ Compile ไฟล์อื่น ให้ส่ง option เดิมพร้อมชื่อไฟล์ เช่น:

```bash
docker-compose run --rm latex \
  -xelatex -interaction=nonstopmode -halt-on-error chapters/example.tex
```

ล้างไฟล์ชั่วคราวที่ LaTeX สร้างขึ้นด้วย:

```bash
docker-compose run --rm latex -C main.tex
```
